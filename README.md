# Карта сообщений о скоплении воды в Актау

На карте приведены архивные сообщения о дождевых подтоплениях. Источники описывают места возле ориентиров, а не точные координаты границ воды: маркер показывает примерное положение ориентира. Уровень подтопления отмечен как неизвестный, если источник не позволяет его определить. Данные не показывают текущую обстановку и не доказывают, что место затапливает при каждом дожде.

В карточке каждого архивного места есть дата сообщения, ссылка на публикацию и ссылка на источник координат ориентира. В исходных данных 29 ориентиров по сообщениям и 98 вымышленных тестовых точек. Тестовые точки не являются наблюдениями и не подтверждают наличие воды или дорог; их можно скрыть переключателем «Показывать тестовые точки». Всего 127 маркеров; это не полный перечень. Ориентиры рядом с адресами из списка акимата могут находиться вблизи участков, уже упомянутых в других публикациях; отдельные маркеры не доказывают разные эпизоды. Ранее использованные вымышленные примеры удалены.

## Запуск

Откройте `index.html` или запустите в папке проекта `python -m http.server` и откройте http://localhost:8000. В Windows можно дважды нажать `Открыть карту.cmd`: требуется Python 3, окно сервера нужно оставить открытым. Карта, адреса и сторонние библиотеки требуют интернета.

## Добавление и перенос собственных наблюдений

Нажмите «Добавить место», затем выберите точку на карте и заполните форму. Наблюдения сохраняются в браузере. Кнопка «Экспорт в JSON» создаёт резервную копию, «Импорт из JSON» добавляет пользовательские точки. Хранилища при открытии файла и локального сервера различаются: переносите наблюдения через экспорт и импорт.

Исходные точки находятся в `data/points.json`; для открытия двойным щелчком их копия находится в `data/points.js`. При изменении JSON обновите и копию: она должна начинаться с `window.EXAMPLE_POINTS = `, после массива добавьте `;`. Не добавляйте непроверенные координаты как точные; указывайте источники и погрешность.

Подложка: Esri и её поставщики данных. При поиске адреса Nominatim/OpenStreetMap получает координаты точки и IP-адрес пользователя.
